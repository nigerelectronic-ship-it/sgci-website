# Site institutionnel SGCI — sgci-niger.com

Vitrine institutionnelle bilingue FR/EN de SGCI SARLU (Société Générale de Commerce et de l'Industrie).

## Déploiement
1. Créer un repo GitHub (ex. `sgci-website`).
2. Uploader : index.html, vercel.json, robots.txt, sitemap.xml, README.md
3. Importer le repo dans Vercel → Deploy.
4. Connecter le domaine sgci-niger.com.
